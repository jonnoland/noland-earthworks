# Field Fix parser fixtures

- `service-log-sample.pdf` and `service-log-sample.docx` are minimal, synthetic Noland Earthworks maintenance records used only for parser verification.
- `word-extractor-test01.doc` is a legacy DOC compatibility fixture from [`morungos/node-word-extractor`](https://github.com/morungos/node-word-extractor), used under that project's MIT License. It verifies extraction from the older binary Word format without requiring a locally installed office suite.
