# Cat Rental Store Quote-Cost Decision

The approved initial approach is an internal Operations quote workspace that opens Cat Rental Store for equipment research and records the actual dealer-provided rental quote, transport, taxes, rental duration, and quote reference. These costs are internal job-cost information only and must not be produced as a customer-facing quote line item.

No public, credential-free Cat Rental Store rate API was identified for this workflow. Caterpillar’s official Digital Marketplace guidance describes its third-party API integration access as requiring a Caterpillar username and access requested through a Cat dealer or Product Link administrator. A future live integration therefore requires separate Cat approval and credentials.

Source: [Caterpillar Digital Marketplace — 3rd Party API Integrations Tool](https://digital.cat.com/news-and-announcements/3rd-party-api-integrations-tool-available)
